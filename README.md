Jewellery Shopping Website

live link : https://hritika-24.github.io/Frotnend-Jewellery-shopping-website-using-html-css-js-bootstrap-/

  This project is a Jewellery Shopping Website designed using HTML, CSS, JavaScript, and Bootstrap. It provides a visually appealing and responsive layout for browsing and purchasing jewellery online.

Features:

  Product Catalog: Displays a collection of jewellery items with images and descriptions.

  Search & Filter Options: Users can search for specific items and filter products by category, price, or material.

  Responsive Design: Ensures a seamless experience across different devices.

  Interactive UI: Smooth animations and transitions for an engaging shopping experience.

Technologies Used:

  HTML: Structure of the website.
  
  CSS: Styling for a visually appealing design.
  
  JavaScript: Adds interactivity and dynamic features.
  
  Bootstrap: Ensures responsiveness and modern UI components.
